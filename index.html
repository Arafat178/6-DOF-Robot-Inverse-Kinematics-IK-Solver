🛠 How to Use (ব্যবহারবিধি)

  1. Target Input: আপনি রোবটের End Effector কে কোথায় পাঠাতে চান, তার X, Y, Z পজিশন এবং Rx, Ry, Rz রোটেশন (Degree) ইনপুট দিন।
  2. Select DH Method: আপনার রোবটটি Standard DH নাকি Modified DH প্যারামিটারে ডিজাইন করা, তা সিলেক্ট করুন (RoboDK বা ইন্ডাস্ট্রিয়াল রোবটের জন্য সাধারণত Modified DH ব্যবহৃত হয়)।
  3. Set Parameters: টেবিলের মধ্যে রোবটের ৬টি লিংকের দৈর্ঘ্য (a, d) এবং টুইস্ট অ্যাঙ্গেল (alpha) বসান।
  4. Set Limits: প্রতিটি জয়েন্ট কত ডিগ্রি পর্যন্ত ঘুরতে পারবে (Min/Max), তা সেট করে দিন।
  5. Calculate: নিচে সবুজ রঙের বাটনে ক্লিক করুন।
  6. Verification: ক্যালকুলেশনের পর নিচে ৩টি ম্যাট্রিক্স দেখতে পাবেন। যদি Difference Matrix-এ সব ভ্যালু ০ এর কাছাকাছি হয়, তবে সলিউশন সঠিক।

📚 Theoretical Background

This solver uses the Jacobian Inverse Method with Damped Least Squares (DLS) to solve Inverse Kinematics for a 6-DOF Robot.

1. Forward Kinematics (FK)

FK calculates the position of the end-effector from joint angles using Homogeneous Transformation Matrices based on DH Parameters:

Ttotal = A1 × A2 × A3 × A4 × A5 × A6

2. Inverse Kinematics (IK) via Jacobian

We use an iterative approach (Numerical Method) because analytical solutions are complex for general 6-DOF robots.

  • Jacobian (J): Relates change in joint angles (dθ) to change in position (dX).
    dX = J × dθ
  • Inverse: To find dθ, we need the inverse:
    dθ = J-1 × dX

3. Damped Least Squares (DLS)

Standard inverse (J-1) fails at Singularities (when robot stretches fully or folds). DLS solves this by adding a damping factor (λ):

J* = JT (J JT + λ2I)-1

This ensures the robot finds a solution without crashing the math engine, even near limits.
